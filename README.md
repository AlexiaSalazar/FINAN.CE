# 💰 FINAN.CE

Sistema web de gerenciamento financeiro pessoal desenvolvido para
organizar receitas, despesas e informações financeiras.

## 🚀 Funcionalidades

- Cadastro e autenticação de usuários
- Registro de receitas
- Registro de despesas
- Controle financeiro
- Histórico de movimentações
- Dashboard
- Visualização de dados financeiros

## 🛠️ Tecnologias

Python
Django
MySQL
HTML
CSS
JavaScript
